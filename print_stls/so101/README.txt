SO-101 individual printable parts

Source: TheRobotStudio/SO-ARM100, official STL/SO101 Prusa plates.
https://github.com/TheRobotStudio/SO-ARM100/tree/main/STL/SO101
Downloaded 2026-11-14. Original Apache-2.0 license included.
Modification: separated meshes and translated to the build plane. No scaling,
rotation or reshaping. Numbered names are extraction IDs, not assembly step numbers.

Leader: 12 files. Follower: 11 files. Choose the appropriate arm folder.
Follower part 05 retains a tiny disconnected source feature in its original
position within the main part footprint, rather than exporting it independently.

PrusaSlicer: choose Original Prusa i3 MK3 with your actual nozzle/material profile.
Import one STL at a time at 100% scale (millimetres). Retain supplied orientation.
Review supports and layer preview before printing; these files are not guaranteed
support-free. If importing several, load as separate objects and arrange them.
Print one copy of each file in the selected folder for the original plate set.
These are stock SO-101 parts, not custom Underbot frame brackets or extended arms.

Validation: all exported meshes are watertight with positive volume; all triangles
retained; dimensions preserved within 0.001 mm; each file fits 250 x 210 x 210 mm.
No physical print or servo fit test performed. See validation.json for dimensions.
